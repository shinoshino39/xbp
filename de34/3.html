Flaskの基本
PythonでWebアプリを作る

Flaskとは

Flaskは、PythonでWebアプリケーションを開発するための軽量なWebフレームワーク。
シンプルな構造で学習しやすく、初心者でも扱いやすい特徴がある。
小規模なWebサイトからWebアプリまで幅広く利用されている。



バックエンドとフロントエンド

バックエンド

サーバー側で処理を行う部分。
FlaskではPythonを使ってデータ処理やページの制御を行う。
例えば、ログイン処理やデータベース操作などを担当する。

フロントエンド

ユーザーが実際に見る画面部分。
HTMLやCSS、JavaScriptを使ってデザインや画面表示を行う。
FlaskではHTMLファイルを表示してWebページを作成する。

Flaskのしくみ

ブラウザからアクセスがあると、FlaskがPythonで処理を行い、
HTMLを返してWebページを表示する。

ブラウザ → Flaskサーバー → Python処理 → HTML表示

簡単なコード例


from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Hello Flask!"

app.run(debug=True)

コードの説明

@app.route("/") はトップページを指定している。
return でブラウザに表示する内容を返している。
app.run() を実行することでFlaskサーバーが起動する。

Flaskのメリット

・シンプルで理解しやすい
・PythonだけでWeb開発できる
・初心者でも学習しやすい
・小規模アプリを作りやすい

感想

Flaskはコード量が少なく、初心者でもWebアプリを作りやすいと感じた。
Pythonで画面表示までできる点が便利だった。
